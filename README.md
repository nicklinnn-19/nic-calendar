# nic日历

给课程与生活，一点有序的空间。

一款适用于 Windows 的本地日历应用。用清爽的日、周、月视图整理课表、日程、生日和纪念日，支持本地 OCR 与课表导入。

**[下载 Windows 公开测试版](https://github.com/nicklinnn-19/nic-calendar/releases)** · [使用说明](使用指南.md) · [反馈问题](https://github.com/nicklinnn-19/nic-calendar/issues)

当前版本：**0.3.6-beta.1**。此仓库只提供程序下载、使用说明与版本记录；项目自有源码暂不公开授权。

## 可以做什么

- **整理日程**：日、周、月视图，搜索、地点、备注、全天与跨天安排。
- **安排课程**：按教学周、单周或双周导入；相同课程稳定配色；完全一致的课程视觉合并，真实冲突并排显示。
- **灵活调课**：修改一堂课时，可选择仅此周调整或应用到整个学期。
- **记住重要日子**：普通日程按公历每天、每周、每月或每年重复；可设置 2—600 次，含首次。
- **自建日历分类**：为生日、纪念日、工作等建立自己的日历并选择颜色。
- **本地识别**：从图片、PDF、Word、Excel 整理课表和上课时间，识别结果可核对、修正后再导入。
- **细致交互**：支持拖动、滚轮、键盘和直接输入的双列时间转轮。
- **本地保存与备份**：托盘提醒、可选开机启动、自动本地备份，以及备份导出和恢复。

## 下载与运行

1. 打开 [Releases](https://github.com/nicklinnn-19/nic-calendar/releases)，下载 `nic-calendar-0.3.6-beta.1-windows-x64.zip`。
2. **完整解压**到固定文件夹，双击其中的 `nic日历.exe`。无需安装 Node.js、Git 或开发环境。
3. 初次使用可先新建日程，或点击侧边栏“导入课表”。

适用平台：**Windows 10 / 11，64 位 x64**。当前没有 macOS、Linux 或 ARM64 专用构建。

程序文件夹中的 DLL、resources、locales 等文件需要保留。GitHub 的 “Source code” ZIP/TAR 只包含本仓库说明文件，**不是可运行程序**。

本测试版尚未进行商业代码签名，Windows 可能显示“未知发行者”。发行页附有 `SHA256SUMS.txt`，可用于核对文件是否与发行包一致。

```powershell
Get-FileHash .\nic-calendar-0.3.6-beta.1-windows-x64.zip -Algorithm SHA256
```

## 数据与提醒

日程存放在本机 `%APPDATA%\nic-calendar\`。公开版使用独立数据目录，不自动读取早期自用版的数据；关闭或移动程序文件夹不会自动删除日程。

OCR 所需引擎与中英文模型随包提供。应用没有账号注册、云同步、遥测或自动更新功能。详见[隐私说明](PRIVACY.md)。

关闭窗口后程序保留在托盘，右键托盘选择“退出”才会停止。提醒需要程序运行且 Windows 允许通知，关机后不提醒。开机启动默认关闭。

## 使用前了解

- 这是公开测试版，重要日程请定期导出备份。
- OCR 结果取决于清晰度和表格排版，请核对学校作息、教学第 1 周的星期一、总周数与单双周后再导入。
- 生日和纪念日目前支持公历；不支持农历或无限次数重复。
- 更新版本时退出托盘程序，解压新版本；保留数据目录并先导出备份。
